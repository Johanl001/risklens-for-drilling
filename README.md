# RiskLens for Drilling

**AI Risk Intelligence for NPT Reduction in Drilling & Well Delivery**

A single-page proposal demonstrating how RiskLens's real-time risk identification approach can be applied to reduce Non-Productive Time (NPT) in oil & gas drilling operations.

## What This Is

A polished, interactive proposal / landing page built as a response to the prompt:
> *"Best use cases for AI to reduce NPT in drilling and well delivery"*

It covers:
- The NPT problem and where it comes from
- Three proposed AI modules (SP-01, WC-02, RC-03)
- A mock driller risk console
- Field evidence from real deployments
- A phased implementation roadmap
- Strategic fit and scoping rationale

## Tech Stack

Pure HTML/CSS — no build step, no dependencies, no frameworks. All charts and diagrams are inline SVG.
